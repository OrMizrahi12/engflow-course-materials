# Claude Code: The Professional Engineering Workflow: course materials

The learner files for the course, one folder per lesson under [`lessons/`](lessons), and a one-page card for each skill
and each workflow under [`cards/`](cards).

The course takes one app, Potluck (a group expense splitter shared by link), from an idea to a live production site with
an engineer's process around Claude Code: align first, a shared language, specs and tickets on GitHub Issues, one change
per worktree and pull request, a mechanical gate, test-first work, evidence, and a safe path to production. Module 10
works in a standalone copy of Spliit (spliit-app/spliit, MIT License), a real open-source app, for triage, debugging and
architecture on code someone else wrote.
