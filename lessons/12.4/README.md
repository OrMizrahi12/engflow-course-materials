# Lesson 12.4: Eyes on production

The lesson's files, exactly as they were typed on camera (commit `Check production's health every hour and open an issue when it fails (#87)`).

| File | What it is |
|---|---|
| `prompts.md` | Every prompt and key shell command run in the lesson, in order |
| `prompts/p_*.txt` | Exact verbatim pasted prompts (`p_impl65`, `p_impl66`, `p_wizard`, `p_answer_wizard`, `p_fix_link`, `p_land_wizard`, `p_loggrep_sentry`, `p_read`, `p_wfa`, `p_push_verify`, `p_impl68`) |
| `eyes-on-production.md` | One-page reference card: two rhythms, `/wizard`, scrubbing, four read-only windows + DB wall, signal vs. noise |
| `potluck-at-lesson-12.4.md` | What tag `lesson-12.4` (`12ea020`) holds and how to check it out |
| `src/app/api/live/route.ts` | Zero-DB liveness route (`200 OK`) |
| `src/app/api/health/route.ts` | Deep health route (reachability, schema currency, storage) |
| `src/sentry/` | Production-only Sentry config, scrubber, and guarded test-error route |
| `src/app/privacy/page.tsx` | Privacy page with the Error reports section |
| `scripts/setup-monitoring.sh` | Re-runnable 6-stage wizard script generated by `/wizard` |
| `.claude/skills/verify/PRODUCTION.md` & `SKILL.md` | Read-only production check routine taught to `verify` |
| `.github/workflows/health.yml` | Hourly health check workflow with 30 s retry and automatic issue open/close |

Run it from your `potluck` project (starting from tag lesson-12.3):

```bash
curl -s https://<your-production-address>/api/health                                          # check live health
claude -w liveness                                                                            # /implement #65
claude -w sentry-errors                                                                       # /implement #66
claude -w sentry-wizard                                                                       # /wizard #67, then run scripts/setup-monitoring.sh
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp/<your-sentry-org>/potluck   # Inspect Issues & Events only
claude -w read-production                                                                     # read production + /writing-for-agents verify skill
claude -w health-hourly                                                                       # /implement #68
```

Vercel Hobby, Neon Free, Sentry Developer Free, GitHub Actions, gh, jq, and mattpocock/skills are free; only the Claude plan is paid. The student kit has the steps for Windows (WSL), macOS and Linux, and what the lesson printed.
